## 📌 О проекте

**Stellar Burger** — одностраничное приложение для выбора и оформления бургеров. Реализована авторизация, конструктор заказа, история заказов.

---

## 🛠️ Стек технологий

- **React** + **TypeScript**
- **Redux Toolkit** (с `createSlice`, `createAsyncThunk`)
- **React Router v6**
- **CSS Modules**
- **Storybook**
- **Webpack**

---

## 🚀 Реализованный функционал

- 🔁 Навигация с помощью `react-router-dom`
- 🔐 Авторизация и регистрация ()
- 🍔 Конструктор бургеров с drag & drop
- 🛠 Управление глобальным состоянием через Redux Toolkit
- ✅ Валидация форм
